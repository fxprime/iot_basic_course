# Classroom Etiquette

Maintaining a respectful environment keeps the live coding sessions productive.

- **Stay on the dashboard.** The instructor uses Tutoriaz to monitor attention. If you must leave,
  notify them via the dashboard chat or quiz response.
- **Use meaningful quiz answers.** Even when a question feels easy, provide context in your reply so
  the instructor can tailor follow-up material.
- **Share findings.** If you discover a wiring fix or code tweak, document it and link to the
  relevant appendix page. The whole cohort benefits.
- **Mute distractions.** Silence notifications and close unrelated tabs during exercises to keep the
  session focused.
