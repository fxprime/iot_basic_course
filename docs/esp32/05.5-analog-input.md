# บทที่ 5.5: Analog Input - การอ่านค่าแบบต่อเนื่อง

ในบทนี้เราจะเรียนรู้การอ่านค่าสัญญาณแบบ Analog (แอนาล็อก) ซึ่งแตกต่างจาก Digital ที่มีแค่ 0 กับ 1 Analog สามารถอ่านค่าได้หลายระดับ เหมาะกับเซนเซอร์แบบต่อเนื่องต่างๆ

## วัตถุประสงค์
- เข้าใจความแตกต่างระหว่าง Digital และ Analog
- ใช้ `analogRead()` อ่านค่าจาก ADC
- ใช้ Potentiometer ปรับค่าแบบต่อเนื่อง
- ใช้ Infrared Sensor ตรวจจับวัตถุ

## ขั้นตอนที่ 1: Digital vs Analog

### 1.1 ความแตกต่าง

**Digital Input (จากบทที่ 5):**
```
0V ───────►  LOW  (0, false)
3.3V ─────►  HIGH (1, true)

มีแค่ 2 สถานะ: ON/OFF
```

**Analog Input (บทนี้):**
```
0V ──────────►  0
0.5V ────────►  621
1.0V ────────►  1241
1.5V ────────►  1862
2.0V ────────►  2482
2.5V ────────►  3103
3.0V ────────►  3724
3.3V ────────►  4095

ค่าต่อเนื่อง: 0 - 4095 (12-bit resolution)
```

<details markdown="1">
<summary>📖 <b>ADC คืออะไร?</b></summary>

### ADC (Analog-to-Digital Converter)

**หน้าที่:** แปลงสัญญาณแรงดันไฟฟ้าเป็นตัวเลข

```
Voltage (Analog)      ADC       Digital Value
     │                 │              │
  0-3.3V          ────►│────►      0-4095
                  Convert
```

### ESP32 ADC Specifications

**12-bit Resolution:**
- Range: 0 - 4095 (2¹² = 4096 steps)
- Step size: 3.3V / 4096 ≈ 0.8mV

**Available Pins:**
```
ADC1 (can be used anytime):
  GPIO 32, 33, 34, 35, 36, 39

ADC2 (avoid when using WiFi):
  GPIO 0, 2, 4, 12, 13, 14, 15, 25, 26, 27
```

**⚠️ คำเตือน:**
- ADC2 ใช้ไม่ได้ขณะเปิด WiFi
- แนะนำใช้ ADC1 (GPIO 32-36, 39) เสมอ

### ตัวอย่างการคำนวณ

**แปลงค่า ADC เป็นแรงดัน:**
```cpp
int adcValue = analogRead(34);
float voltage = (adcValue / 4095.0) * 3.3;
```

**ตัวอย่าง:**
```
ADC = 2048 → Voltage = (2048/4095) × 3.3 = 1.65V
ADC = 4095 → Voltage = (4095/4095) × 3.3 = 3.30V
ADC = 0    → Voltage = (0/4095) × 3.3 = 0V
```

</details>

### 1.2 Pinout ที่ใช้ ADC

- GPIO 34, 35, 36, 39 → Input only (ใช้ ADC ได้ดีที่สุด)

## ขั้นตอนที่ 2: Potentiometer - ปรับค่าแบบต่อเนื่อง

### 2.1 รู้จักกับ Potentiometer

**Potentiometer (VR, Variable Resistor)** = ตัวต้านทานปรับค่าได้

![Potentiometer](../assets/images/potentiometer-10k.png)

**ลักษณะ:**
- 3 ขา: VCC, Output, GND
- หมุนซ้าย-ขวา ได้แรงดันต่างกัน
- ช่วง 10KΩ (WH148-B10K)

**การต่อวงจร:**
```
Potentiometer    ESP32
--------------   ------
VCC (ขา 1)    →  3.3V
OUT (ขา 2)    →  GPIO 34 (ADC)
GND (ขา 3)    →  GND
```

### 2.2 อ่านค่า Potentiometer

```cpp
const int POT_PIN = 34;  // ADC1_CH6

void setup() {
  Serial.begin(115200);
  pinMode(POT_PIN, INPUT);
  
  Serial.println("=== Potentiometer Test ===");
  Serial.println("Turn the knob...");
}

void loop() {
  int adcValue = analogRead(POT_PIN);
  
  Serial.print("ADC Value: ");
  Serial.print(adcValue);
  Serial.print("\t(0-4095)");
  
  // แปลงเป็นแรงดัน
  float voltage = (adcValue / 4095.0) * 3.3;
  Serial.print("\tVoltage: ");
  Serial.print(voltage, 2);  // 2 ทศนิยม
  Serial.print("V");
  
  // แปลงเป็นเปอร์เซ็นต์
  int percent = map(adcValue, 0, 4095, 0, 100);
  Serial.print("\tPosition: ");
  Serial.print(percent);
  Serial.println("%");
  
  delay(100);
}
```

**Output:**
```
ADC Value: 0      (0-4095)    Voltage: 0.00V   Position: 0%
ADC Value: 512    (0-4095)    Voltage: 0.41V   Position: 12%
ADC Value: 2048   (0-4095)    Voltage: 1.65V   Position: 50%
ADC Value: 4095   (0-4095)    Voltage: 3.30V   Position: 100%
```

## ขั้นตอนที่ 3: Infrared Sensor - ตรวจจับวัตถุ

### 3.1 รู้จักกับ Infrared Barrier Module

**IR Sensor** = เซนเซอร์ตรวจจับวัตถุด้วยแสงอินฟราเรด

![IR Sensor Module](../assets/images/ir-sensor-module.png)

**คุณสมบัติ:**
- LED Transmitter (ส่งแสง IR)
- Photo Transistor (รับแสง IR)
- Comparator + Potentiometer (ปรับความไว)
- Digital Output (HIGH = ไม่เจอ, LOW = เจอวัตถุ)

**การทำงาน:**
```
ไม่มีวัตถุ:
  IR TX ──────►  ──────► IR RX  →  Output = HIGH (1)

มีวัตถุ:
  IR TX ──────►  ◄──|──  IR RX  →  Output = LOW (0)
                    วัตถุสะท้อน
```

### 3.2 การต่อวงจร

```
IR Sensor      ESP32
----------     ------
VCC         →  5V (หรือ 3.3V)
GND         →  GND
OUT         →  GPIO 33 (Digital)
```

**⚠️ หมายเหตุ:** เซนเซอร์นี้ให้ output แบบ Digital (0/1) แต่มี **Potentiometer** ปรับ threshold บนบอร์ด

### 3.3 ทดสอบ IR Sensor

```cpp
const int IR_PIN = 33;
const int LED_PIN = 2;  // Built-in LED

void setup() {
  Serial.begin(115200);
  pinMode(IR_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  
  Serial.println("=== IR Sensor Test ===");
  Serial.println("Bring object close to sensor...");
}

void loop() {
  int irState = digitalRead(IR_PIN);
  
  if (irState == LOW) {  // Active LOW
    Serial.println("🔴 Object DETECTED!");
    digitalWrite(LED_PIN, HIGH);
  } else {
    Serial.println("⚪ No object");
    digitalWrite(LED_PIN, LOW);
  }
  
  delay(200);
}
```

### 3.4 Line Follower Application

```cpp
const int IR_LEFT = 32;
const int IR_RIGHT = 33;

void setup() {
  Serial.begin(115200);
  pinMode(IR_LEFT, INPUT);
  pinMode(IR_RIGHT, INPUT);
  
  Serial.println("=== Line Follower Logic ===");
  Serial.println("Place sensors on line...");
}

void loop() {
  bool leftSensor = digitalRead(IR_LEFT);
  bool rightSensor = digitalRead(IR_RIGHT);
  
  // LOW = เจอเส้นดำ, HIGH = พื้นขาว
  if (leftSensor == LOW && rightSensor == LOW) {
    Serial.println("▲ Forward - Both on line");
  }
  else if (leftSensor == LOW && rightSensor == HIGH) {
    Serial.println("◄ Turn Left - Left on line");
  }
  else if (leftSensor == HIGH && rightSensor == LOW) {
    Serial.println("► Turn Right - Right on line");
  }
  else {
    Serial.println("⏹ Stop - No line detected");
  }
  
  delay(200);
}
```

### 3.5 ปรับความไว

บนโมดูลจะมี **Potentiometer** สำหรับปรับความไว:

1. หมุนตามเข็มนาฬิกา → เพิ่มความไว (ตรวจจับไกลขึ้น)
2. หมุนทวนเข็มนาฬิกา → ลดความไว (ต้องอยู่ใกล้)

**LED บนบอร์ด:**
- เปิด = ตรวจจับวัตถุ
- ดับ = ไม่เจอวัตถุ

## ขั้นตอนที่ 4: Passive Buzzer - เสียงตามค่า Analog

### 4.1 รู้จักกับ Passive Buzzer

**Passive Buzzer** = ลำโพงที่ต้องส่ง PWM สร้างเสียง

![Passive Buzzer](../assets/images/passive-buzzer.png)

**เปรียบเทียบ:**

| Active Buzzer | Passive Buzzer |
|--------------|----------------|
| มีวงจรออสซิลเลเตอร์ภายใน | ไม่มีวงจรสร้างความถี่ |
| ให้ไฟเดี๋ยว = เสียงดัง | ต้องส่ง PWM |
| เสียงความถี่เดียว | สร้างเสียงหลายความถี่ได้ |

**วิธีแยก:**
- Active → มีสติ๊กเกอร์ปิด, เห็น PCB สีดำ
- Passive → เห็นโครงสร้างภายใน, เหมือนลำโพง

### 4.2 การต่อวงจร

```
Passive Buzzer   ESP32
--------------   ------
VCC (+)       →  GPIO 25 (PWM)
GND (-)       →  GND
```

### 4.3 ทดสอบ Buzzer

```cpp
const int BUZZER_PIN = 25;

void setup() {

  // เล่นโน้ต G (392 Hz)
  tone(BUZZER_PIN, 392);

  // หยุดเสียง
  noTone(BUZZER_PIN);
  Serial.println("♪ -");
  delay(500);
}
```

## ขั้นตอนที่ 5: โปรเจครวม - Analog Control Panel

### 5.1 Multi-Sensor Dashboard

```cpp
const int POT_PIN = 34;
const int IR_PIN = 33;
const int BUZZER_PIN = 25;
const int LED_PIN = 2;

int lastAdcValue = -1;
bool lastIrState = true;

void setup() {
  Serial.begin(115200);
  
  pinMode(POT_PIN, INPUT);
  pinMode(IR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_PIN, OUTPUT);
  
  Serial.println("╔══════════════════════════════════╗");
  Serial.println("║   Analog Control Panel           ║");
  Serial.println("╚══════════════════════════════════╝");
  Serial.println("");
}

void loop() {
  // อ่านค่า Potentiometer
  int adcValue = analogRead(POT_PIN);
  int percent = map(adcValue, 0, 4095, 0, 100);
  
  // อ่านค่า IR Sensor
  bool irDetected = (digitalRead(IR_PIN) == LOW);
  
  // แสดงผลเมื่อมีการเปลี่ยนแปลง
  if (abs(adcValue - lastAdcValue) > 50 || irDetected != lastIrState) {
    Serial.println("┌──────────────────────────────┐");
    
    // Potentiometer
    Serial.print("│ Potentiometer: ");
    Serial.print(percent);
    Serial.print("%");
    if (percent < 10) Serial.print("  ");
    else if (percent < 100) Serial.print(" ");
    Serial.println("        │");
    
    // Bar graph
    Serial.print("│ [");
    int bars = percent / 5;  // 20 ช่อง
    for (int i = 0; i < 20; i++) {
      Serial.print(i < bars ? "█" : "░");
    }
    Serial.println("] │");
    
    // IR Sensor
    Serial.print("│ IR Sensor: ");
    Serial.print(irDetected ? "DETECTED 🔴" : "Clear ⚪   ");
    Serial.println(" │");
    
    Serial.println("└──────────────────────────────┘");
    Serial.println("");
    
    lastAdcValue = adcValue;
    lastIrState = irDetected;
  }
  
  // ควบคุม Buzzer ตาม Potentiometer
  if (percent > 10) {  // เปิดเสียงเมื่อหมุนเกิน 10%
    int frequency = map(percent, 10, 100, 200, 1000);
    tone(BUZZER_PIN, frequency);
  } else {
    noTone(BUZZER_PIN);
  }
  
  // ควบคุม LED ตาม IR
  digitalWrite(LED_PIN, irDetected ? HIGH : LOW);
  
  delay(100);
}
```

### 5.2 Alarm System (IR + Buzzer)

```cpp
const int IR_PIN = 33;
const int BUZZER_PIN = 25;
const int LED_PIN = 2;

bool alarmArmed = false;
unsigned long alarmStartTime = 0;

void setup() {
  Serial.begin(115200);
  
  pinMode(IR_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  pinMode(LED_PIN, OUTPUT);
  
  Serial.println("=== Alarm System ===");
  Serial.println("Send 'A' to arm/disarm");
}

void loop() {
  // คำสั่ง Serial
  if (Serial.available()) {
    char cmd = Serial.read();
    if (cmd == 'A' || cmd == 'a') {
      alarmArmed = !alarmArmed;
      Serial.print("Alarm: ");
      Serial.println(alarmArmed ? "ARMED ✓" : "DISARMED");
      if (!alarmArmed) {
        noTone(BUZZER_PIN);
        digitalWrite(LED_PIN, LOW);
      }
    }
  }
  
  // ตรวจจับ
  if (alarmArmed) {
    bool detected = (digitalRead(IR_PIN) == LOW);
    
    if (detected) {
      // แสดงสถานะ
      if (millis() - alarmStartTime > 500) {  // แสดงทุก 0.5s
        Serial.println("⚠️  INTRUDER DETECTED!");
        alarmStartTime = millis();
      }
      
      // สัญญาณเตือน (เสียงสลับ)
      unsigned long now = millis();
      if ((now / 200) % 2 == 0) {
        tone(BUZZER_PIN, 1000);  // High pitch
        digitalWrite(LED_PIN, HIGH);
      } else {
        tone(BUZZER_PIN, 500);   // Low pitch
        digitalWrite(LED_PIN, LOW);
      }
    } else {
      noTone(BUZZER_PIN);
      digitalWrite(LED_PIN, LOW);
    }
  }
  
  delay(50);
}
```

### 5.3 Analog Sequencer (Music Box)

```cpp
const int POT_PIN = 34;
const int BUZZER_PIN = 25;

// เพลง: Twinkle Twinkle Little Star
int melody[] = {
  262, 262, 392, 392, 440, 440, 392,  // C C G G A A G
  349, 349, 330, 330, 294, 294, 262,  // F F E E D D C
  392, 392, 349, 349, 330, 330, 294,  // G G F F E E D
  392, 392, 349, 349, 330, 330, 294,  // G G F F E E D
  262, 262, 392, 392, 440, 440, 392,  // C C G G A A G
  349, 349, 330, 330, 294, 294, 262   // F F E E D D C
};
int noteDurations[] = {
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2,
  4, 4, 4, 4, 4, 4, 2
};
const int NUM_NOTES = sizeof(melody) / sizeof(melody[0]);

void setup() {
  Serial.begin(115200);
  pinMode(POT_PIN, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  
  Serial.println("=== Music Box ===");
  Serial.println("Turn pot to control speed");
}

void loop() {
  int adcValue = analogRead(POT_PIN);
  
  // ความเร็ว: 50-500ms per beat
  int tempo = map(adcValue, 0, 4095, 50, 500);
  
  for (int i = 0; i < NUM_NOTES; i++) {
    // อ่าน pot ใหม่ทุกโน้ต
    adcValue = analogRead(POT_PIN);
    tempo = map(adcValue, 0, 4095, 50, 500);
    
    int duration = tempo / noteDurations[i];
    
    tone(BUZZER_PIN, melody[i]);
    
    Serial.print("Note ");
    Serial.print(i + 1);
    Serial.print("/");
    Serial.print(NUM_NOTES);
    Serial.print(" - Tempo: ");
    Serial.print(tempo);
    Serial.println("ms");
    
    delay(duration);
    noTone(BUZZER_PIN);
    delay(duration * 0.3);  // Gap
  }
  
  Serial.println("♪ Song finished!");
  delay(2000);
}
```

## ขั้นตอนที่ 6: Advanced Topics

### 6.1 Smoothing (กรองสัญญาณรบกวน)

```cpp
const int POT_PIN = 34;
const int NUM_READINGS = 10;

int readings[NUM_READINGS];
int readIndex = 0;
int total = 0;
int average = 0;

void setup() {
  Serial.begin(115200);
  pinMode(POT_PIN, INPUT);
  
  // Initialize array
  for (int i = 0; i < NUM_READINGS; i++) {
    readings[i] = 0;
  }
  
  Serial.println("=== Smoothing Example ===");
}

void loop() {
  // อ่านค่าใหม่
  int rawValue = analogRead(POT_PIN);
  
  // ลบค่าเก่า, เพิ่มค่าใหม่
  total = total - readings[readIndex];
  readings[readIndex] = rawValue;
  total = total + readings[readIndex];
  
  // เลื่อน index
  readIndex = (readIndex + 1) % NUM_READINGS;
  
  // คำนวณค่าเฉลี่ย
  average = total / NUM_READINGS;
  
  // แสดงผล
  Serial.print("Raw: ");
  Serial.print(rawValue);
  Serial.print("\tSmoothed: ");
  Serial.println(average);
  
  delay(100);
}
```

### 6.2 Threshold Detection

```cpp
const int POT_PIN = 34;
const int LED_PIN = 2;

const int THRESHOLD_LOW = 1000;
const int THRESHOLD_HIGH = 3000;

enum Level {
  LOW_LEVEL,
  MEDIUM_LEVEL,
  HIGH_LEVEL
};

Level currentLevel = MEDIUM_LEVEL;

void setup() {
  Serial.begin(115200);
  pinMode(POT_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int adcValue = analogRead(POT_PIN);
  Level newLevel;
  
  // กำหนดระดับ
  if (adcValue < THRESHOLD_LOW) {
    newLevel = LOW_LEVEL;
  } else if (adcValue > THRESHOLD_HIGH) {
    newLevel = HIGH_LEVEL;
  } else {
    newLevel = MEDIUM_LEVEL;
  }
  
  // แสดงเมื่อมีการเปลี่ยนแปลง
  if (newLevel != currentLevel) {
    currentLevel = newLevel;
    
    Serial.print("Level changed: ");
    switch (currentLevel) {
      case LOW_LEVEL:
        Serial.println("LOW ▁");
        digitalWrite(LED_PIN, LOW);
        break;
      case MEDIUM_LEVEL:
        Serial.println("MEDIUM ▄");
        digitalWrite(LED_PIN, HIGH);
        break;
      case HIGH_LEVEL:
        Serial.println("HIGH █");
        digitalWrite(LED_PIN, HIGH);
        break;
    }
  }
  
  delay(100);
}
```

### 6.3 Calibration (ปรับเทียบ)

```cpp
const int POT_PIN = 34;

int sensorMin = 4095;  // เริ่มต้นสูงสุด
int sensorMax = 0;     // เริ่มต้นต่ำสุด

void setup() {
  Serial.begin(115200);
  pinMode(POT_PIN, INPUT);
  
  Serial.println("=== Calibration Mode ===");
  Serial.println("Turn potentiometer fully left and right");
  Serial.println("Calibrating for 5 seconds...");
  
  unsigned long startTime = millis();
  while (millis() - startTime < 5000) {
    int sensorValue = analogRead(POT_PIN);
    
    // บันทึกค่า min/max
    if (sensorValue > sensorMax) {
      sensorMax = sensorValue;
    }
    if (sensorValue < sensorMin) {
      sensorMin = sensorValue;
    }
    
    delay(50);
  }
  
  Serial.println("Calibration complete!");
  Serial.print("Min: ");
  Serial.println(sensorMin);
  Serial.print("Max: ");
  Serial.println(sensorMax);
  Serial.println("");
}

void loop() {
  int rawValue = analogRead(POT_PIN);
  
  // ใช้ค่าที่ปรับเทียบแล้ว
  int calibratedValue = map(rawValue, sensorMin, sensorMax, 0, 100);
  calibratedValue = constrain(calibratedValue, 0, 100);
  
  Serial.print("Raw: ");
  Serial.print(rawValue);
  Serial.print("\tCalibrated: ");
  Serial.print(calibratedValue);
  Serial.println("%");
  
  delay(200);
}
```

## แบบฝึกหัด

### โจทย์ที่ 1: LED Brightness Control
ใช้ Potentiometer ควบคุมความสว่าง LED (PWM)
- อ่านค่า ADC จาก pot
- แปลงเป็น PWM (0-255)
- ส่งไปยัง LED

### โจทย์ที่ 2: Parking Sensor
สร้างเซนเซอร์จอดรถด้วย IR + Buzzer
- เมื่อตรวจจับวัตถุ → เสียง beep เร็วขึ้น
- ใช้ Potentiometer จำลองระยะทาง

### โจทย์ที่ 3: Analog Gauge
แสดงค่า ADC แบบ gauge บน Serial Monitor
```
    0%          50%         100%
    |-----------|-----------|
         ▲
     Current: 42%
```

### โจทย์ที่ 4: Multi-IR Line Follower
ใช้ IR sensor 3 ตัว สร้างรถเดินตามเส้น
- แสดงสถานะทั้ง 3 sensor พร้อมกัน
- แสดงทิศทางที่ต้องเลี้ยว
