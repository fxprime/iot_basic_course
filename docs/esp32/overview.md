# ESP32 Course Overview

Welcome to the ESP32 interactive course. This curriculum blends short theory segments with
hands-on labs that you can follow inside the Tutoriaz dashboard.

## Learning Goals

1. Understand the ESP32 architecture and toolchain setup.
2. Configure digital and analog peripherals for classroom demos.
3. Build Wi-Fi enabled projects that communicate with simple servers.
4. Practice troubleshooting techniques with guided checklists.

## Course Structure

| Module | Focus Area                     | Key Deliverables                |
| ------ | ----------------------------- | -------------------------------- |
| 01     | Board bring-up and GPIO basics | LED sequencing sketch            |
| 02     | Networking foundations         | Wi-Fi connection manager script  |
| 03     | Sensors and data acquisition   | Serial telemetry dashboard       |
| 04     | Capstone integration           | Connected classroom mini-project |

> **Tip:** In live sessions the instructor can push quizzes directly into Tutoriaz. Keep this
docs tab open in a second window so you can cross-reference instructions while responding to
quizzes.
